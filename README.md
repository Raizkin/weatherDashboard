# Weather Dashboard

A responsive, Ukrainian/English weather dashboard transferred from the local RAIZKIN portfolio source.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Features

- Search cities in English or Ukrainian, including transliteration.
- Live current conditions, the next 12 hours, and a 7-day forecast.
- Switch temperature units between Celsius and Fahrenheit.
- Quick destinations for Kyiv, Lviv, Odesa, London, and Prague.
- Forecast and geocoding data from Open-Meteo; no API key is required.

The project uses Next.js, React, Tailwind CSS, and Lucide icons.
